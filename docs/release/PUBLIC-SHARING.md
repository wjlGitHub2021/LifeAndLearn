# 公开展示发布

> 状态：准备中；完成状态以本页的实际验证记录为准。
> 授权日期：2026-09-28

## 范围与目的

将本地单用户 MVP 的源码和使用说明放入用户自己的 GitHub 公开仓库，并在个人网站 `https://orizuru.top/LifeAndLearn` 提供一页介绍、仓库入口和简短的本地体验步骤。该页面只通过完整路径访问，不加入站内导航、作品列表、站内搜索或站点地图。路径可被知道地址的人访问，不构成访问控制。

应用本身继续在使用者本机运行；不将当前 SQLite、模型 API Key 或本机服务部署到公网。公开展示使用的是产品说明及本地运行路径。

## 发布边界

- 源码、测试与非敏感项目文档可以公开；`data/`、`tmp/`、`var/`、`.tmp/`、依赖、构建产物、环境变量和日志必须排除。
- 公开前核对仓库实际跟踪文件、凭据扫描、路径和文档链接；用全新克隆验证安装、类型检查、自动化测试及生产构建。
- 网站页需核对桌面与窄屏布局、目标 URL、GitHub 链接、`noindex`、站点地图和站内搜索排除；不改用户现有网站工作树的其他未提交内容。
- 面试/英语示例须标明场景用途，不冒充真实用户成绩或长期学习效果；第三方模型调用需要体验者自己的 API Key。

## 风险与恢复

公开仓库的内容可被复制，误上传的凭据不能仅靠删除仓库恢复；如发现泄漏，应立即撤销相应凭据并审查公开历史。网站页面可通过后续部署撤回，仓库可改为私有，但已被获取的副本无法收回。因此只从审查后的文件集创建首次提交。

网站发布若出现页面错误，回退本次网站提交并重新部署；本地应用数据和运行中的 `3000` 服务不参与网站发布。仓库发布若发现功能问题，以修订提交修复，不重写公共历史。
