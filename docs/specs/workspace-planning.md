# 工作区日程与趋势增量规格

> 状态：2026-09-27 用户已确认改版方向；PI1—PI6 已在本地实现并完成逐块及最终独立 QA，证据见[验收记录](../quality/MVP-VERIFICATION.md#工作区日程与趋势增量验收2026-09-27)。本文保留吸顶顶部、设置、日期语义和真实趋势图的行为真源；原「本周」页面结构已由[一体化工作区规格](integrated-workspace.md)增量替代。原事项执行及 Agent 指标规则仍见[事项工作台规格](workbench-v2.md)与[Agent 管理规格](agent-management.md)。

## 目标与范围

当前工作台能查看待办、成果与 Agent 历史，但用户无法直接看接下来一周安排，也不易从逐条记录看出活动趋势。此次让用户在一个本地工作区中回答：本周哪天处理什么、哪些事项尚未安排、Agent 过去一段时间实际交付了什么。

本轮只管理站内快捷事项与自定义 Agent 事项。计划日期、截止日、主题与模型连接由用户控制；不接入外部日历、不发送提醒、不自动运行或自动排期、不把运行次数推断为学习效果。现有业务记录不填虚构日期或图表数值。

## 页面结构与设置

```text
左侧：工作台 / 我的事项 / 本周 / Agent 事项 / Agent 团队 / 资料与记忆
顶部（滚动时保留）：当前页面 | DeepSeek 状态 | 设置
设置弹窗：使用偏好 / 外观 / 模型连接 / 数据与隐私 / 使用说明
工作台：需要你参与 / 本周安排入口 / 最近成果 / 创建事项
Agent 团队：既有近 7 天指标 / 7 或 30 天真实趋势 / 实例与详情
```

- 桌面侧栏和右侧正文仍分别滚动；右侧顶栏在正文滚动时保持可见，窄屏顶栏收紧布局，不遮挡标题、焦点或弹窗。
- 外观设置继续保持“固定明暗”与“主题色”互斥，并分别记住原选择；移入设置弹窗后，切主题、关弹窗或切页面均不丢未保存事项草稿。
- 使用偏好允许选择下次打开工作区的默认页面（工作台、我的事项、日程与数据）和日程默认周/月视图；与主题一样只保存在当前浏览器。页面内临时切换不修改偏好，也不影响事项、排期或模型运行。
- 顶栏持续显示模型连接状态；点击状态直达模型连接区，设置按钮先打开使用偏好，再可切到模型连接。API Key 仍只在后端内存，不因弹窗引入浏览器持久化、日志或数据库存储。设置不提供尚未实现的数据导入、导出、备份或删除按钮。
- 数据与隐私页展示当前库可核对的事项、Agent 与有效偏好计数，明确资料发送边界及管理入口；使用说明提供原页面跳转，不复制 Agent 权限、偏好或事项编辑表单到设置中。
- 弹窗有明确标题、关闭入口、Escape 关闭、焦点进入与返回、可用键盘操作；Agent 职责、资料权限和实例偏好继续在所属 Agent/记忆界面管理。

## 本周日程

- 两类事项各保存可选 `planned_date`（计划处理日）、`due_date`（截止日），格式为本机日历日期 `YYYY-MM-DD`；两者都为空时归入“未安排”。只填截止日时仍在未安排区显示截止日，不冒充计划处理日。若两者都有值，计划日不可晚于截止日。
- 本轮为日期级计划，不表示钟点、时长块或系统提醒。原快捷事项的“你的参与时间”仍是预算估计，不自动变成日历占用；自定义 Agent 事项也不伪造时长。
- 用户可从新建/编辑事项或“本周”视图明确设置、修改、清空日期。改期是组织元数据：不进入模型输入、不扩大资料权限、不使已生成成果失效，也不取消正在运行的模型请求。排期有独立并发修订，陈旧写入提示刷新核对，不覆盖其他页面的新安排。
- “本周”按浏览器本地星期一至星期日显示，可前后切周并回到今天；每天展示计划在该日的快捷与 Agent 事项，区分待处理、已完成和逾期截止。点卡片进入原事项详情。开放且未设置计划日的事项在未安排区可见；归档事项不占当前日程，仍可从历史列表查看。
- 截止日只是用户输入的提示，过期不会自动完成、归档、启动 Agent 或触发模型调用。空数据时显示如何创建/安排事项的入口，不预填演示事项。

## Agent 真实趋势

- Agent 团队保留既有 7×24 小时指标与下钻；另提供 7/30 天切换的趋势图，只统计自定义 Agent 事项的实际运行及已确认成果，快捷事项不混入。
- 趋势图按首次读取时刻向前取 N 个连续 24 小时区间，最右侧为最近 24 小时；图上说明为滚动时间段，悬停/键盘聚焦显示每段准确起止时间。7 天趋势与原近 7 天指标口径一致。
- 每段可切换查看启动运行、成功、失败、已确认成果；同一次运行成功不等于事项完成，已确认成果不等于学习水平提高。无记录时显示真实零值与引导说明，不画虚构趋势。
- 点击任一区间打开对应原始事件，支持分页；钻取范围与数量固定在首次读取的时间及事件序号高水位，后续新写入不混入旧页。图表和列表的时间、指标、Agent 事项范围须一致。鼠标、键盘及窄屏均能读取数值，不只靠颜色区分。

## 兼容、迁移与恢复

- 日期列及独立排期修订对旧记录增量添加，旧记录日期为 `null`。每条数据链迁移前沿用同目录 `VACUUM INTO` 一致备份；事务失败不得留下半个迁移。重复启动幂等，原事项、运行、成果、连接状态和权限不变。
- 排期 API 仅接受有效日期、合法事项类型和匹配的排期修订；范围外或陈旧请求有明确错误。新 API 不暴露 API Key；所有读写仍由本机同源保护。主题持久化仍在浏览器本地。
- 不改变 DeepSeek 供应商、真实模型调用协议、历史版本引用、Agent 运行调度或旧版 `/legacy` 数据。

## 验收场景

| 编号 | 可观察结果 |
|---|---|
| PI1 | 桌面右侧滚动时顶栏留在视口、左侧导航不随正文滚动；390px 窄屏能操作顶栏与弹窗，无横向溢出。 |
| PI2 | 设置弹窗中主题互斥及各自选择持久有效；模型状态与连接操作仍可用，Key 不进入持久层；草稿不因弹窗丢失。 |
| PI3 | 两类事项可独立设计划日与截止日；周视图准确跨周显示、未安排区保留只填截止日的事项、逾期仅提示；完成/归档与详情跳转正确。 |
| PI4 | 改期不更改内容修订或模型输入哈希，不废弃旧成果或取消运行；陈旧排期更新被拒，旧库备份、回填、重复迁移及回滚通过隔离测试。 |
| PI5 | 7/30 天趋势数值由真实事件投影，7 天总数与现有指标一致；点击区间看到同口径原始事件，空库不显示假数据。 |
| PI6 | 团队趋势、周视图、设置与旧事项入口在桌面/窄屏、刷新和隔离进程重启后可用；没有业务测试数据写入用户当前数据库。 |
